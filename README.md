# LoRaCode

Firmware für das LoRa-Temperaturmessnetz (Feather M0 + RFM95, 868 MHz).

| Pfad | Inhalt |
|---|---|
| `LoRa_eingebaut/` | Aktuelle Knoten-Firmware |
| `LoRa_integriert/` | Aktuelle Knoten-Firmware |
| `empfaenger/` | Empfänger-Firmware: Feather M0 + RFM95 am USB-Port der Basisstation, gibt Pakete als `Start Receive: <id>,<temp> :End Receive` seriell aus |
| `OldCode/` | Frühere Entwicklungsstände, nicht mehr aktiv |
